# Project
📊 SQL Job Market Analysis
📌 Project Overview

This project analyzes job market data using SQL to identify trends related to high-paying jobs, in-demand skills, and the skills associated with higher salaries.

The analysis is designed to answer practical questions such as:

What are the highest-paying jobs?
Which skills are associated with high-paying jobs?
Which skills are most in demand?
Which skills offer the highest salaries?
What skills provide the best combination of demand and salary?

The project demonstrates the use of SQL for data exploration, aggregation, filtering, grouping, sorting, and analytical problem-solving.

🔎 SQL Analysis
1. Top Paying Jobs

File: 1_top_paying_jobs.sql

Identifies the highest-paying jobs in the dataset and provides insight into which job roles offer the greatest salaries.

2. Top Paying Job Skills

File: 2_top_paying_job_skills.sql

Analyzes the skills associated with high-paying job positions to understand which technical or professional skills appear in higher-paying roles.

3. Top Demanded Skills

File: 3_top_demanded_skills.sql

Identifies the skills that are most frequently requested by employers, helping highlight skills with strong demand in the job market.

4. Top Paying Skills

File: 4_top_paying_skills.sql

Analyzes salary information by skill to identify skills associated with higher-paying opportunities.

5. Top Optimal Skills

File: 5_top_optimal_skills.sql

Combines skill demand and salary potential to identify skills that provide a strong balance between being frequently requested and offering attractive compensation.

🛠️ Tools & Technologies
SQL – Data analysis and querying
CSV – Data storage
GitHub – Project version control and documentation
🎯 Key Objectives

The main objectives of this project are to:

Analyze job market data using SQL.
Identify high-paying job opportunities.
Find the most demanded skills.
Discover skills associated with higher salaries.
Identify optimal skills based on both demand and salary.
Demonstrate practical SQL data-analysis skills.

The analysis can help job seekers and aspiring data professionals understand:

Which job roles tend to offer higher salaries.
Which skills employers are actively looking for.
Which skills are associated with higher compensation.
Which skills may provide a good combination of market demand and earning potential.
